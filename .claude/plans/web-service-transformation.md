# План: Превращение в полноценный веб-сервис

## Цель
Превратить локальное приложение для управления проектами в полноценный SaaS-сервис с возможностью регистрации пользователей, многопользовательской работой и облачным развертыванием.

## Текущее состояние
- ✅ Next.js 14 с App Router
- ✅ NextAuth.js для аутентификации
- ✅ Prisma ORM + PostgreSQL
- ✅ Базовая система пользователей (admin, manager, engineer)
- ✅ Управление проектами и задачами
- ✅ История изменений
- ✅ Комментарии и вложения
- ❌ Публичная главная страница (сейчас редирект на /login)
- ❌ Полноценная регистрация новых пользователей
- ❌ Многопользовательская работа с разделением доступа
- ❌ Email уведомления
- ❌ Облачное хранилище файлов

## Приоритеты (по ответам пользователя)
1. **Регистрация новых пользователей** - полноценная система с подтверждением email
2. **Многопользовательская работа** - разграничение прав, личные и общие проекты
3. **Облачный хостинг** - развертывание на Vercel/Railway
4. **Email уведомления** - SendGrid/Resend
5. **Хранилище файлов** - S3/Cloudinary

## Фазы реализации

**Задачи**:

2. Переместить текущий функционал в защищенную зону
   - `/projects` → `/dashboard/projects`
   - `/admin` → `/dashboard/admin`
   - `/calendar` → `/dashboard/calendar`

3. Создать layout для публичных страниц
   - Навигационное меню (Главная, О нас, Возможности, Цены, Войти)
   - Адаптивный дизайн

**Файлы для создания/изменения**:

### Фаза 3: Многопользовательская работа
**Цель**: Разделение проектов на личные и командные, разграничение доступа

**Задачи**:
1. Обновить схему базы данных

2. API для управления доступом

3. Обновить UI проектов

**Файлы для создания/изменения**:

## Технологический стек (дополнения)

### Email
- **Resend** (https://resend.com)
  - 3,000 emails/month бесплатно
  - Простое API
  - React Email для шаблонов

### Файловое хранилище
- **Cloudinary** (https://cloudinary.com)
  - 25 GB storage бесплатно
  - Автоматическая оптимизация
  - CDN

### Хостинг
- **Vercel** для Next.js приложения
  - Бесплатный hobby план
  - Автоматический deployment
  - Edge Network

- **Neon** или **Supabase** для PostgreSQL
  - Бесплатный tier с ограничениями
  - Managed database
  - Автобэкапы

### Мониторинг (опционально)
- **Sentry** для отслеживания ошибок
- **Vercel Analytics** для метрик

2. **Фаза 2** (Регистрация) - 3-4 часа

5. **Фаза 5** (Файлы) - 2-3 часа
6. **Фаза 6** (Деплой) - 2-3 часа

**Общее время**: 15-22 часа чистой работы

## Риски и рекомендации

1. **База данных**: При переходе на облако нужно будет пересоздать БД или мигрировать данные
2. **Email лимиты**: Resend дает 3000 писем/месяц бесплатно - этого хватит на старте
3. **Файлы**: Существующие файлы в base64 нужно будет мигрировать в Cloudinary
4. **Тарифные планы**: Пока не реализовываем платные планы, только free tier
5. **Безопасность**: Обязательно настроить rate limiting для API routes
