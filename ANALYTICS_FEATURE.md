# Аналитика проекта - Документация

## Реализованные функции

### 1. Страница аналитики проекта
**URL:** `/projects/[id]/analytics`

### 2. Основные компоненты

#### Карточки метрик
- **Всего задач** - общее количество задач в проекте
- **Завершено** - количество завершенных задач
- **Среднее время** - среднее время выполнения задачи (в днях)
- **Узкое место** - этап, на котором задачи застревают

#### Прогресс выполнения
- Визуальная шкала прогресса с процентом завершения

#### Графики
1. **Время по этапам (Bar Chart)**
   - Показывает среднее время выполнения на каждом этапе
   - Помогает выявить, где задачи задерживаются дольше всего

2. **Задачи по статусам (Pie Chart)**
   - Распределение задач по текущим статусам
   - Цветовая кодировка для быстрой оценки

#### Таблица статистики по этапам
Показывает для каждого этапа:
- Количество задач
- Среднее время выполнения
- Количество застрявших задач (>7 дней)
- Статус этапа:
  - 🔴 **Узкое место** - есть застрявшие задачи
  - 🟡 **Медленно** - время > 1.5x от среднего
  - 🟢 **Нормально** - работает эффективно

#### Детализация по задачам
Таблица со всеми задачами проекта:
- Название задачи
- Текущий этап
- Статус
- Исполнитель
- Время выполнения с цветовой индикацией:
  - 🔴 Красный: > 2x от среднего
  - 🟡 Желтый: > 1.5x от среднего
  - ⚪ Обычный: нормальное время

### 3. API Endpoint
**URL:** `/api/projects/[id]/analytics`

**Возвращаемые данные:**
```typescript
{
  projectId: number;
  projectName: string;
  totalTasks: number;
  completedTasks: number;
  avgCompletionTime: number; // в днях
  bottleneckStage: string | null; // этап с узким местом
  tasks: TaskAnalytics[];
  stageStats: StageAnalytics[];
  tasksByStatus: StatusDistribution[];
  timeByStage: TimeByStage[];
}
```

### 5. Навигация
Добавлена вкладка "Аналитика" в навигацию проекта (`ProjectNav.tsx`)

## Как использовать

1. Откройте проект: `/projects/[id]`
2. Перейдите на вкладку "Аналитика"
3. Изучите метрики и графики
4. Обратите внимание на красные индикаторы - это узкие места
5. Проверьте задачи с большим временем выполнения в таблице детализации

## Технологии
- **Next.js 14** - App Router
- **Recharts** - библиотека графиков
- **Prisma** - ORM для работы с БД
- **Tailwind CSS** - адаптивная стилизация
- **TypeScript** - типизация

## Формулы расчета

### Время выполнения задачи
```typescript
timeSpent = completedAt 
  ? (completedAt - createdAt) / (24 * 60 * 60 * 1000)
  : (now - createdAt) / (24 * 60 * 60 * 1000)
```

### Застрявшие задачи
Задача считается застрявшей, если:
- Находится в одном статусе > 7 дней
- Статус не "Завершено"

### Узкое место
Этап с наибольшим количеством застрявших задач или самым долгим средним временем выполнения.
