### 2. API Endpoints (21 шт.)

**Проекты:**
- `GET/POST /api/projects` — список и создание
- `GET/PATCH/DELETE /api/projects/[id]` — детали, обновление, удаление
- `GET/POST /api/projects/[id]/tasks` — задачи проекта

**Задачи:**
- `PATCH/DELETE /api/tasks/[id]` — обновление, удаление
- `POST /api/tasks/reorder` — изменение порядка (drag & drop)

**Пользовательские столбцы:**
- `GET/POST /api/columns` — список и создание
- `GET/PATCH/DELETE /api/columns/[id]` — управление столбцом
- `GET/PATCH /api/columns/[id]/values` — значения полей

**Уведомления:**
- `GET /api/notifications` — список уведомлений
- `PATCH /api/notifications/[id]/read` — отметить прочитанным
- `POST /api/notifications/mark-all-read` — отметить все

**Комментарии и история:**
- `GET/POST /api/comments` — комментарии
- `GET /api/activity` — история изменений

**Dashboard и календарь:**
- `GET /api/dashboard/summary` — статистика
- `GET /api/calendar/events` — события календаря

**Пользователь:**
- `GET/PATCH /api/user/settings` — настройки
- `GET/PATCH /api/user/profile` — профиль
- `PATCH /api/user/password` — смена пароля

**Администрирование:**
- `GET/POST /api/admin/users` — управление пользователями
- `GET/PATCH/DELETE /api/admin/users/[id]` — CRUD пользователя

### 3. Вспомогательные библиотеки

- `lib/access-control.ts` — проверка прав доступа
- `lib/activity-log.ts` — логирование изменений
- `lib/notifications.ts` — создание уведомлений
- `lib/email/` — отправка писем с шаблонами

### 4. Аутентификация (NextAuth.js)

- Регистрация с подтверждением email
- Вход/выход

- Шаблоны напоминаний о дедлайнах

### 6. Документация

- `QUICKSTART.md` — быстрый старт за 5 минут

## 🚀 Как запустить (когда PostgreSQL готов)

```bash
# 1. Установите зависимости
npm install --legacy-peer-deps

# 2. Настройте .env (DATABASE_URL, NEXTAUTH_SECRET)
# Уже готово! Только обновите DATABASE_URL с реальным паролем PostgreSQL

# 3. Применить миграции
npx prisma migrate dev --name init

# 4. Заполнить демо-данными
npm run seed

# 5. Запустить сервер
npm run dev

# 6. Открыть в браузере
http://localhost:3000

# 7. Войти с тестовыми данными
Email: admin@example.com
Пароль: Admin12345!
```
