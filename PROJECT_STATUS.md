## 🚀 Следующие шаги

1. **Настроить Cloudinary** (опционально):
   - Зарегистрироваться на https://cloudinary.com
   - Получить API ключи
   - Добавить в `.env`

2. **Протестировать загрузку файлов**:
   - Открыть любой проект
   - Нажать "📎 Файлы"
   - Загрузить файл через drag & drop

3. **Реализовать глобальный поиск** (следующая задача)

## 📝 Известные ограничения

- Максимальный размер файла: 10 МБ (лимит Next.js API)
- Cloudinary бесплатно: 25 GB storage, 25 GB bandwidth/месяц
- Email SMTP нужно настраивать вручную
