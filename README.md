# Project Tracker

Веб-сайт для управления проектами и задачами. Открывается в браузере, требует
регистрации, хранит все данные в PostgreSQL, отправляет email-уведомления.

Этот README написан в расчёте на то, что вы **никогда раньше не запускали
код разработчика**. Идите по шагам подряд, не пропуская.

\---

## Что реализовано на данный момент (Этап 1)

* Регистрация (имя, email, пароль, подтверждение пароля)
* Подтверждение email по ссылке из письма
* Вход (email + пароль), блокировка входа без подтверждённого email
* Восстановление пароля через email
* Хранение пользователей в PostgreSQL, пароли — только в хэшированном виде

Таблица проектов, задачи, фильтры, уведомления и остальное из ТЗ будут
добавляться следующими этапами поверх этой же базы.

## Шаг 1. Установите Node.js

1. Перейдите на https://nodejs.org
2. Скачайте версию **LTS** (рекомендованную) для вашей операционной системы.
3. Установите как обычную программу (next → next → finish).
4. Проверьте установку. Откройте терминал:

   * **Windows**: нажмите Win, введите "PowerShell", откройте
   * **Mac**: откройте приложение "Terminal"
Введите:

```
   node -v
   ```

Если видите номер версии (например `v20.14.0`) — всё установилось.

## Шаг 2. Установите PostgreSQL

Проще всего — через Docker (см. вариант A). Если не хотите ставить Docker —
вариант B (обычная установка PostgreSQL).

### Вариант A: через Docker (рекомендуется)

1. Установите Docker Desktop: https://www.docker.com/products/docker-desktop
2. После установки откройте терминал в папке проекта и выполните:

```
   docker run --name project-tracker-db -e POSTGRES\\\\\\\\\\\\\\\_PASSWORD=postgres -e POSTGRES\\\\\\\\\\\\\\\_DB=project\\\\\\\\\\\\\\\_tracker -p 5432:5432 -d postgres:16
   ```

Это скачает и запустит PostgreSQL в фоне.

3. Строка подключения для `.env` (см. Шаг 4):

```
   DATABASE\\\\\\\\\\\\\\\_URL="postgresql://postgres:postgres@localhost:5432/project\\\\\\\\\\\\\\\_tracker?schema=public"
   ```

### Вариант B: обычная установка

1. Скачайте PostgreSQL: https://www.postgresql.org/download/
2. Во время установки задайте пароль для пользователя `postgres` — запомните его.
3. Создайте базу данных с именем `project\\\\\\\\\\\\\\\_tracker` (через pgAdmin, который
ставится вместе с PostgreSQL: правой кнопкой на "Databases" → Create → Database).
4. Строка подключения будет вида:

```
   DATABASE\\\\\\\\\\\\\\\_URL="postgresql://postgres:ВАШ\\\\\\\\\\\\\\\_ПАРОЛЬ@localhost:5432/project\\\\\\\\\\\\\\\_tracker?schema=public"
   ```

## Шаг 3. Распакуйте проект и установите зависимости

1. Распакуйте архив с проектом в удобную папку.
2. В терминале перейдите в эту папку, например:

```
   cd Downloads/project-tracker
   ```

3. Установите все библиотеки проекта (займёт пару минут):

```
   npm install
   ```

## Шаг 4. Настройте файл .env

1. В папке проекта найдите файл `.env.example`.
2. Сделайте его копию и переименуйте копию в `.env` (точка в начале имени обязательна).
3. Откройте `.env` любым текстовым редактором и заполните:

   * `DATABASE\\\\\\\\\\\\\\\_URL` — строка из Шага 2.
   * `NEXTAUTH\\\\\\\\\\\\\\\_SECRET` — любая случайная длинная строка. Можно сгенерировать
командой в терминале: `openssl rand -base64 32` (Mac/Linux), либо просто
придумать 40+ случайных символов.
   * `NEXTAUTH\\\\\\\\\\\\\\\_URL` и `APP\\\\\\\\\\\\\\\_URL` — оставьте `http://localhost:3000` для локального запуска.
   * `SMTP\\\\\\\\\\\\\\\_\\\\\\\\\\\\\\\*` и `EMAIL\\\\\\\\\\\\\\\_FROM` — настройки вашей почты (см. Шаг 7). Пока можно
оставить пустыми — письма будут просто печататься в консоль вместо реальной отправки.

## Шаг 5. Создайте таблицы в базе данных (миграции)

```
npx prisma migrate dev --name init
```

Эта команда создаст в базе данных все нужные таблицы согласно схеме проекта.

## Шаг 6. Заполните демо-данными (необязательно, но полезно для первого входа)

```
npm run seed
```

Это создаст администратора:

* email: `admin@example.com`
* пароль: `Admin12345!`

Email у этого пользователя уже считается подтверждённым, так что вы сразу
сможете войти под ним, не настраивая почту.

## Шаг 7. (Опционально на этом этапе) Настройте отправку email

Чтобы реально получать письма (подтверждение регистрации, сброс пароля и
далее — напоминания о дедлайнах), нужен SMTP-доступ. Варианты:

* **Yandex почта**: SMTP\_HOST=`smtp.yandex.ru`, порт `465` или `587`,
логин — полный email, пароль — специальный "пароль приложения"
(создаётся в настройках безопасности Яндекс ID).
* **Gmail**: похожим образом нужен "пароль приложения" (App Password),
обычный пароль от аккаунта Google не подойдёт.
* **Сервисы для рассылок** (проще для продакшена): Mailgun, SendGrid, Resend —
у них есть готовые SMTP-реквизиты после регистрации.

Впишите данные в `.env` в переменные `SMTP\\\\\\\\\\\\\\\_HOST`, `SMTP\\\\\\\\\\\\\\\_PORT`, `SMTP\\\\\\\\\\\\\\\_USER`,
`SMTP\\\\\\\\\\\\\\\_PASSWORD`, `EMAIL\\\\\\\\\\\\\\\_FROM`. Если оставить пустыми — приложение не упадёт,
просто вместо отправки письма будет писать в консоль сервера, что письмо
"отправлено бы туда-то".

## Шаг 8. Запустите сайт

```
npm run dev
```

Откройте в браузере: http://localhost:3000

Вы попадёте на страницу входа. Можно:

* Войти как демо-администратор (Шаг 6), либо
* Зарегистрироваться самостоятельно — тогда, если настроен SMTP (Шаг 7),
придёт письмо со ссылкой подтверждения; если SMTP не настроен, ссылку
подтверждения нужно будет взять из консоли терминала, где выводится лог
(`\\\\\\\\\\\\\\\[email:DRY-RUN] ...`) — либо посмотреть напрямую в базе данных таблицу
`verification\\\\\\\\\\\\\\\_tokens`.

## Сборка и запуск в production (когда сайт будет готов к размещению)

```
npm run build
npm run start
```

Приложение можно разместить на любом VPS с Node.js (не привязано к
конкретному хостингу), либо на платформах вроде Railway/Render, которые
поддерживают Node.js + PostgreSQL "из коробки". Не забудьте отдельно
запустить cron/worker процесс (`npm run worker`) — он появится на этапе
реализации email-напоминаний.
