## 📝 Примечания

### Текущая структура БД

База данных полностью спроектирована и содержит все необходимые таблицы:

- `users` — пользователи
- `projects` — проекты
- `tasks` — задачи
- `custom_columns` — пользовательские столбцы
- `custom_field_values` — значения пользовательских полей
- `comments` — комментарии
- `activity_log` — история изменений
- `notifications` — уведомления
- `user_settings` — настройки пользователей
- `verification_tokens` — токены подтверждения email
- `password_reset_tokens` — токены сброса пароля

### API маршруты

Уже созданы:
- `/api/auth/*` — NextAuth endpoints ✅
- `/api/test-db` — проверка подключения к БД ✅
- `/api/projects` — CRUD проектов ✅
- `/api/projects/[id]` — детали, обновление, удаление проекта ✅
- `/api/projects/[id]/tasks` — задачи проекта ✅
- `/api/tasks/[id]` — обновление, удаление задачи ✅
- `/api/tasks/reorder` — изменение порядка задач ✅
- `/api/columns` — пользовательские столбцы ✅
- `/api/columns/[id]` — обновление, удаление столбца ✅
- `/api/columns/[id]/values` — значения пользовательских полей ✅

- `/api/dashboard/summary` — статистика для dashboard ✅
- `/api/calendar/events` — события календаря ✅
- `/api/user/settings` — настройки пользователя ✅
- `/api/user/profile` — профиль пользователя ✅
- `/api/user/password` — изменение пароля ✅
