# Настройка Cloudinary для загрузки файлов

Cloudinary — это облачный сервис для хранения и оптимизации файлов (изображений, документов, видео).

**Преимущества:**
- ✅ Бесплатно 25 GB хранилища
- ✅ Автоматическое сжатие изображений
- ✅ CDN для быстрой загрузки по всему миру
- ✅ Автоматическое преобразование форматов (WebP, AVIF)
- ✅ Защита от потери файлов

---

## 1. Регистрация в Cloudinary

1. Перейдите на https://cloudinary.com
2. Нажмите "Sign Up" (регистрация)
3. Заполните форму или войдите через Google/GitHub
4. Подтвердите email

---

## 2. Получение API ключей

1. После входа откройте **Dashboard**
2. В разделе "Account Details" найдите:
   - **Cloud name** (например: `dxyz123`)
   - **API Key** (например: `123456789012345`)
   - **API Secret** (нажмите "Reveal" чтобы увидеть)

3. Скопируйте эти данные

---

## 3. Настройка проекта

Откройте файл `.env` в корне проекта и заполните:

```env
CLOUDINARY_CLOUD_NAME="ваш-cloud-name"
CLOUDINARY_API_KEY="ваш-api-key"
CLOUDINARY_API_SECRET="ваш-api-secret"
```

**Пример:**
```env
CLOUDINARY_CLOUD_NAME="dxyz123"
CLOUDINARY_API_KEY="123456789012345"
CLOUDINARY_API_SECRET="AbCdEfGhIjKlMnOpQrStUvWxYz"
```

---

## 4. Перезапуск сервера

После настройки переменных окружения перезапустите сервер:

```bash
npm run dev
```

---

## 5. Использование

### Загрузка файлов

1. Откройте любой проект
2. Нажмите кнопку "📎 Загрузить файл"
3. Перетащите файл или выберите через диалог
4. Файл автоматически загрузится в Cloudinary

### Что происходит при загрузке:

1. Файл отправляется на сервер
2. Сервер загружает файл в Cloudinary
3. Cloudinary возвращает URL файла
4. URL сохраняется в базе данных
5. Файл доступен через CDN по всему миру

### Удаление файлов

1. Нажмите "🗑️" возле файла
2. Файл удалится из Cloudinary и базы данных

---

## 6. Лимиты бесплатного плана

- **Storage:** 25 GB
- **Bandwidth:** 25 GB/месяц
- **Transformations:** 25 кредитов/месяц
- **Requests:** Unlimited

Для большинства проектов этого более чем достаточно!

---

## 7. Безопасность

⚠️ **Важно:**
- Не публикуйте `.env` файл в репозиторий
- API Secret должен оставаться секретным
- При деплое на Vercel/Railway добавьте переменные окружения в настройках платформы

---

## 8. Альтернативы (если Cloudinary не подходит)

Если вы хотите использовать другой сервис:

### Uploadcare
- https://uploadcare.com
- Бесплатно: 3000 файлов, 3 GB storage

### ImageKit
- https://imagekit.io  
- Бесплатно: 20 GB bandwidth/месяц

### Supabase Storage
- https://supabase.com
- Бесплатно: 1 GB storage

Для переключения нужно будет изменить только файл `src/lib/cloudinary.ts`

---

## Готово!

Теперь вы можете загружать файлы в облако вместо хранения в базе данных. Это ускорит работу приложения и снизит нагрузку на сервер.
