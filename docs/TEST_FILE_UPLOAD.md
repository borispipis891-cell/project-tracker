# Тестирование загрузки файлов через Cloudinary

## Шаг 1: Настройка Cloudinary

1. Зарегистрируйтесь на https://cloudinary.com
2. После входа откройте **Dashboard**
3. В разделе "Account Details" скопируйте:
   - **Cloud name**
   - **API Key** 
   - **API Secret** (нажмите "Reveal")

4. Откройте `.env` и заполните:
```env
CLOUDINARY_CLOUD_NAME="ваш-cloud-name"
CLOUDINARY_API_KEY="ваш-api-key"
CLOUDINARY_API_SECRET="ваш-api-secret"
```

5. Перезапустите сервер:
```bash
npm run dev
```

---

## Шаг 2: Тест загрузки

1. Откройте http://localhost:3001
2. Войдите как `admin@test.com` / `admin123`
3. Откройте любой проект из списка
4. Нажмите кнопку **"📎 Файлы"** справа от названия проекта
5. В открывшемся модальном окне вы увидите зону загрузки

---

## Шаг 3: Загрузите файл

**Вариант A: Drag & Drop**
1. Перетащите файл (изображение, PDF, документ) в зону загрузки
2. Увидите прогресс-бар
3. После загрузки файл появится в списке

**Вариант B: Выбор файла**
1. Кликните на зону загрузки
2. Выберите файл через диалог
3. Файл загрузится автоматически

---

## Шаг 4: Проверка результата

**Что должно произойти:**
1. ✅ Файл загружается в Cloudinary
2. ✅ URL файла сохраняется в базе данных
3. ✅ Файл появляется в списке вложений
4. ✅ Для изображений показывается превью

**Для изображений:**
- Увидите миниатюру 48x48px слева от названия
- Cloudinary автоматически оптимизирует качество

**Для других файлов:**
- Увидите иконку 📎

---

## Шаг 5: Тест скачивания

1. Нажмите кнопку **"⬇"** возле файла
2. Файл откроется в новой вкладке
3. Можете скачать его через браузер

---

## Шаг 6: Тест удаления

1. Нажмите кнопку **"✕"** возле файла
2. Подтвердите удаление
3. Файл удалится из Cloudinary и базы данных

---

## Что проверить

### ✅ Загрузка работает:
- Изображения (JPG, PNG, GIF, WebP)
- Документы (PDF, DOCX, XLSX)
- Архивы (ZIP, RAR)

### ✅ Лимиты:
- Максимальный размер: 10 МБ
- При превышении должна быть ошибка

### ✅ Оптимизация:
- Cloudinary автоматически сжимает изображения
- Формат выбирается автоматически (WebP для современных браузеров)

---

## Проверка в Cloudinary Dashboard

1. Откройте https://cloudinary.com
2. Перейдите в **Media Library**
3. Найдите папку `project-tracker/project-{id}`
4. Там должны быть все загруженные файлы

---

## Если что-то не работает

### Ошибка "Failed to upload"
- Проверьте правильность API ключей в `.env`
- Убедитесь что перезапустили сервер после изменения `.env`

### Файл не появляется в списке
- Откройте консоль браузера (F12)
- Проверьте наличие ошибок
- Убедитесь что размер файла не превышает 10 МБ

### Ошибка 403 (Access Denied)
- Убедитесь что вы вошли как владелец проекта или участник с правами "editor"
